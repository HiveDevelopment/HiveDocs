# Adding a Node

Add a Node when you are connecting a new machine to HivePanel or expanding available capacity.

## 1. Prepare the host

Follow [Preparing a Node](/installation/node-preparation) and install Worker according to the current release instructions.

## 2. Create the Node in Panel

Open the Node administration area and create the Node record. Use a descriptive name that makes the machine easy to identify operationally.

## 3. Configure connectivity

Apply the Worker connection details generated or required by Panel to the Worker configuration on the Node.

## 4. Start Worker

Start or restart Worker and verify that the Node becomes connected in Panel.

## 5. Test placement

Deploy a test Cell to the Node before moving production workloads onto it.

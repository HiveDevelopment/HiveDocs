# Your first Cell

1. [Install Panel](/installation/panel) and sign in as the administrator created by the installer.
2. Add a Node under **Admin → Nodes**, then [install its Worker](/installation/worker).
3. Add the IP/port allocations that Node can use.
4. Open **Admin → Combs → HiveRegistry** and import a suitable Comb.
5. Create a Cell: choose its owner, Node, Comb, allocation, resources and variables.
6. Wait for installation to finish, then start it from the console.

Confirm that console output, resource statistics and file uploads work before adding real workloads. For a website, [connect a domain](/cells/domains). For Minecraft, see [content installers](/cells/content).

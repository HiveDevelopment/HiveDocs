# Switch Comb

Open **Cell → Switch Comb** to select another template offered by the administrator.

1. Stop the Cell.
2. Choose the Comb and one of its offered images.
3. Review variables and the installation/replacement confirmation.
4. Save an instance first if you want to return to the old setup.
5. Confirm and follow installation progress.

Existing files may not be compatible with the new workload. Back up or save an instance before replacing them. For large worlds, save the instance separately and wait for it to complete before switching.

Admins choose permitted Combs under **Admin → Cell Features**. Switching does not grant more resources or allocations. Use **Startup** for a variable/image change that does not need a new template.

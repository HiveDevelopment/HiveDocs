# Minecraft content

Minecraft Cells have dedicated pages for **JARs, mods, plugins and modpacks**, backed by HiveRegistry.

1. Select the Minecraft version and compatible server/loader.
2. Search the appropriate catalogue and choose a version.
3. Open the installation preview and review dependencies and replacements.
4. Confirm the installation, then follow its progress and logs.

Use a plugin-capable server for plugins and a matching mod loader for mods. The selected Java image must support that server version.

## Modpacks

A pack can replace the existing server. Read the wipe/replacement confirmation and back up files or [save an instance](/cells/instances) before accepting it. One-click installation depends on the provider's downloadable files and supported server manifest.

The pack builder lets you choose a Minecraft version and loader, add suggested content, review dependency checks, save a pack and export it. Metadata checks cannot guarantee every mod combination will work.

Provider API keys stay in HiveRegistry. Some provider-restricted files or packs that need a separate custom server installer cannot be installed automatically. Use the failure details rather than repeatedly starting the Cell during an install.

# Instances

Instances keep different server setups within one Cell—for example, a survival world and a modpack.

1. Stop the Cell and open **Instances**.
2. Save a copy of the current setup, or create an empty instance.
3. Wait for the save to finish.
4. Activate the setup you want to use, then start the Cell.

Switching restores that instance's files, Comb, variables, image and startup settings together. File Manager shows the active setup and provides an instance selector. Reconnect SFTP after switching.

Only one instance runs at a time. All saved files count towards the same Cell disk allowance; external databases and backups are not automatically versioned with them. Delete an inactive instance only when its files are no longer needed.

If synchronization was interrupted after activation, retry activating the same instance to finish. For separate simultaneous servers, use [Server Splitter](/cells/splitter).

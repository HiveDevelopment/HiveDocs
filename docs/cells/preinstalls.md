# Application preinstalls

Preinstalls are one-click application setups offered by a Comb—for example, a Discord bot starter.

Open the Cell's **Preinstalls** page, choose a preset, review its preview and confirm any file replacement. Follow progress until installation completes, then configure required runtime secrets and start the application.

A recipe can clone a repository, download/extract assets, run build steps and copy files. Administrators author and offer these recipes; users select from those offers. Recipe builds use isolated staging, rather than running arbitrary user instructions on the Node host.

A successful install does not create a Discord application, obtain a bot token or configure external databases for you. Follow the preset's instructions and keep secrets out of screenshots and exports.

See [Combs](/combs/) and [HiveRegistry](/registry/) for publishing offers.

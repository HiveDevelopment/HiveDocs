# Install Worker

Worker is a system service on each Node. Panel uses Docker Compose; Worker manages the separate Docker containers that run Cells.

1. In **Admin → Nodes**, create the Node with its connection address and ports.
2. Open the Node's **Configuration** page and generate a registration token.
3. Copy its **One-click installer** command and run it on that Node.
4. Return to Panel and confirm the Node is registered and reachable.
5. Add allocations, import a Comb and create a test Cell.

Use the command generated by your own Panel: it includes that Panel's URL and the one-time registration token. Keep it private. Existing registered Workers do not need a fresh token during normal updates.

## Check the service

```bash
systemctl status hiveworker --no-pager -l
journalctl -u hiveworker -n 80 --no-pager
```

The installed configuration normally lives at `/etc/hivepanel/worker.yml`. If connectivity fails, check [networking](/nodes/networking) and [troubleshooting](/troubleshooting/).

Keep the Worker and Panel on compatible releases. Install game runtimes through the Comb's image rather than installing Java or Node.js on the host.

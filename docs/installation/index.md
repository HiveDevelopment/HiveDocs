# Installation

Use the installer for production. It deploys Panel with Docker Compose, including its database, Redis, web server, queue and scheduler.

1. Check [host requirements](/installation/requirements).
2. [Install Panel](/installation/panel) once.
3. [Install Worker](/installation/worker) on each Node.
4. [Create a test Cell](/getting-started/quick-start).

You do not need to install PHP, Composer, MariaDB or Redis manually on the Panel host. Source builds are covered under [development](/development/setup).

Updating an existing installation? Use [Updates & repair](/maintenance/upgrading), rather than the fresh-install flow.

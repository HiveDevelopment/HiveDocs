# Reporting a Problem

A useful bug report makes the problem reproducible without exposing secrets.

## Include

- HivePanel Panel version
- Worker version
- operating system and relevant runtime versions
- what you expected to happen
- what actually happened
- steps to reproduce
- relevant Panel and Worker errors
- the affected Comb when applicable

## Remove secrets

Redact API keys, Worker credentials, session cookies, database passwords and other authentication material before sharing logs or configuration publicly.

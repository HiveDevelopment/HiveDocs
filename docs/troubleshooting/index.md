## Getting help

If you cannot isolate the problem, collect the relevant versions, steps and logs described in [Reporting a Problem](/troubleshooting/reporting).

::: warning Do not publish secrets
Remove Worker credentials, API keys, session values and passwords before sharing logs or configuration.
:::

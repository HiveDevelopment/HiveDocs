# Introduction

HivePanel is a modern, open source platform for deploying, managing and scaling game servers across infrastructure you control.

The documentation is organised around the same concepts you see in the product: **Panel**, **Nodes**, **Worker**, **Cells** and **Combs**.

## New to HivePanel?

Start with the [Quick Start](/getting-started/quick-start) for the shortest path to a running game server, or read [How HivePanel Works](/guide/how-it-works) first if you want to understand the architecture.

## Installing HivePanel

The [Installation](/installation/) section covers the control plane and Node setup separately. Panel is installed once; Worker is installed on every Node that will run Cells.

## Running game servers

Once infrastructure is connected, use the [Cells](/cells/) section for day-to-day server management and the [Combs](/combs/) section for reusable server definitions.

## Operating the platform

Node capacity, user access, updates, recovery and troubleshooting are covered in the administration and maintenance sections.

::: tip HivePanel terminology
A **Cell** is a running game server instance. A **Comb** describes how that type of Cell is installed and started.
:::

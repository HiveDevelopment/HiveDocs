# HivePanel

HivePanel manages game servers, websites and applications on infrastructure you control.

| Term | What it means |
| --- | --- |
| Panel | The web interface and central API. |
| Node | A Linux machine or VM that hosts workloads. |
| Worker | The system service on a Node that manages Docker and Cell files. |
| Cell | One server, website or application. |
| Comb | The template that defines a Cell's image, variables, installation and startup. |
| HiveRegistry | The catalogue for Combs, Minecraft content and preinstall recipes. |

# Nodes

A Node is a physical machine or virtual machine that provides compute capacity to HivePanel.

Each Node runs an instance of Worker. Worker connects the Node to Panel and manages the Cells hosted on that machine.

A Node can host multiple Cells according to its available CPU, memory, storage and networking capacity. Add more Nodes when you need additional capacity, geographic locations or operational separation between workloads.

See the full [Node documentation](/nodes/) for setup and operations.

# Account Security

Protect Panel accounts because administrative access can control the workloads running across your infrastructure.

## Passwords

Use unique, strong passwords and a password manager. Never share administrator accounts between operators.

## Authentication controls

Enable additional authentication protections provided by the HivePanel release you are running and enforce them for privileged users where appropriate.

## Sessions

Sign out unused sessions and revoke access promptly when a user no longer needs Panel access.

## Auditability

Use available audit information to understand who made significant changes to infrastructure and Cells.

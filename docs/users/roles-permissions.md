# Roles and Permissions

Use roles and permissions to control which parts of HivePanel a user can access and what actions they can perform.

## Administrative access

Infrastructure administration can affect multiple Cells or entire Nodes. Reserve these permissions for trusted operators.

## Operational access

Where possible, grant Cell-specific capabilities such as console, files, backups or schedules independently.

## Review regularly

Remove permissions that are no longer required when responsibilities change. Periodic access reviews are especially important for installations operated by larger teams.
